# flow-neutral-demo

A small public repository that runs [Figentra Flow](https://github.com/figentra/flow) with its `neutral` preset,
GitHub Issues as the tracker and GitHub Actions as the runner. It exists to show Flow working outside the repositories
it was built in: every change here goes from an issue, through a spec and its gates, to a merged pull request.

The code is deliberately tiny. The point is the path a change takes, not the code.
